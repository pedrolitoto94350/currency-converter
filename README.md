# Currency Converter React App

This is a simple currency converter React application using a free API for exchange rates.

## How to run locally

1. Open your terminal and navigate to the project directory:
```
cd ~/.openclaw/workspace/currency-converter
```

2. Install dependencies (if not already done):
```
npm install
```

3. Start the development server:
```
npm start
```

4. Open your browser and go to:
```
http://localhost:3000
```

You will see the currency converter app running locally.
